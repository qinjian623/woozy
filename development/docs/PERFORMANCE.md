记录日期：2026-11-10。测试源码提交为 `b7e1414d06bb1b6f0812bb5d581896302a8d821e`。后续 README 和本文的命名修改不改变该次测试的编译器代码。

四配置检查：Release 83、Debug 83、ASan/UBSan 83、LLVM OFF 41，共 290 项通过，无失败、跳过。检查范围是现有 v0.1 语法和 SEMANTICS 中已定义的核心要求，完整标准库及明确延后的扩展另做。

## 正式测速

机器：AMD Ryzen 7 8745HS，Linux x86_64，固定 CPU 1。Woozy 和等价手写 C++ 实现均使用 O2、通用 x86-64，禁用 fast-math、FMA 和 LTO。

每组从 C++ 的 R=1 开始倍增校准，每个 R 保留 3 次运行，选择首个中位数至少 500ms 且最小值至少 250ms 的 R，并保留 2R 对照。双方分别热身 2 次，再做 9 对交替计时。算法代码、C++ 对照和测试脚本位于 [tests/performance](../../tests/performance)。

下表耗时为完整进程执行 R 轮的中位耗时，单位为毫秒，包含内存管理和完整结果检查。耗时比为 Woozy 中位耗时除以 C++ 中位耗时，每组均须不超过 2；不计算跨算法平均值来抵消超标项。

首轮有 14 组完成；另两组因 CPU 连续忙碌，在执行任何程序之前停止，之后串行补齐。没有删除或替换已经计时的样本。原始记录及独立检查保留在本地开发目录，未随源码上传；本文提供结果摘要，不声称换一台机器可得到相同比值。

正式测试的 16 个 Woozy 程序均无 ELF INTERP、NEEDED 或强未定义符号，不依赖 libc/libstdc++。编译器自身仍使用 C++/LLVM。运行库空闲小块内存页缓存总上限为 12MiB，活对象所在页另计。
