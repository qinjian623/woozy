# nativeemit E fixture

`run.py` copies the production packages from `--source-root` into a fresh
temporary project, always overlays the E files from `--e-source` (default: this
worktree), runs stage0 `check`, and reports one of:

- `passed`: the whole package checked and the C adapter fixture built and ran;
  the generated C11 source also passed `clang -std=c11 -fsyntax-only`.
- `partial`: only E (and the packages currently present) could be checked
  because sibling B/C/D/layout/verify/valueops files are not merged.  The
  report names the missing cross-group functions and marks full build/run as
  `not_run`.  Parse errors, type errors and duplicate declarations still fail.
- `failed`: anything else.

The fixture in `main.wz` builds a tiny frozen schema-v2 `model.Project` with a
record, a resource, a static callback and a managed registration.  It then
calls `finalize_c_adapter` and prints the generated C source.  This exercises
record layout assertions, buffer/resource wrappers, static callback and
registration trampolines, the registration dispatcher and all three adapters
without calling the old C++ `cffi` generator.

Example:

```sh
python3 selfhost/tests/nativeemit_e/run.py \
  --woozyc /path/to/build/woozy-stdlib-native/woozyc \
  --toolchain-root /path/to/toolchains \
  --work-dir /tmp/nativeemit-e
```

The work directory contains `results.json`, every command's stdout/stderr and
the generated `adapter.c` when the full package is available.

## SH08e production-fix probes

`fix_check.py` builds a fresh project from the frozen Root joint candidate,
overlays only the E files from this worktree, copies the read-only independent
`review.wz` (five original cases) plus `e_review_extra.wz`, and runs:

- stage0 `check`, native `build --opt 0` and `build --opt 2`, then both programs;
- `opt -passes=verify` on every generated module (the five review cases and the
  combined runtime bundle);
- `runtime_driver.c` linked with the real `liblang_native_runtime.a` and the
  test-only scalar ABI wrapper `runtime_wrapper.ll`, covering getenv
  present/missing/negative-errno, getenv_bytes, the three IPC waits, and
  bool/i32/nested-record/pointer field results.

The wrapper is test-only: it adapts the generated by-value aggregate ABI to the
C driver; it does not change or weaken the generated IR. `results.json` is the
latest evidence. `run.py` remains the 3835-byte C adapter equality control; its
latest evidence is in `adapter_results.json`.

```sh
python3 selfhost/tests/nativeemit_e/fix_check.py \
  --work-dir /tmp/woozy-sh08e-e-full \
  --results selfhost/tests/nativeemit_e/results.json
```
